# 수수료 절감 및 볼륨 거래 최적화 기능 제안

## 현재 로직 분석

현재 봇은 다음과 같은 방식으로 작동합니다:
- **Maker 주문으로 오픈**: 시장가 근처에 리미트 주문 (낮은 수수료)
- **Maker 주문으로 클로즈**: Take-profit 가격에 리미트 주문 (낮은 수수료)
- **Boost 모드**: Maker 오픈 + Taker 마켓 클로즈 (더 높은 수수료, 빠른 실행)

## 수수료 절감을 위한 제안 기능

### 1. Post-Only 주문 강제 (Post-Only Order Enforcement)

**목적**: 실수로 Taker 주문이 되는 것을 방지하여 항상 Maker 수수료를 받도록 보장

**구현 방법**:
- 모든 리미트 주문에 `post_only=True` 플래그 추가
- 주문이 즉시 체결될 경우 취소하고 가격 조정 후 재주문
- 거래소별 Post-Only API 지원 확인 및 구현

**예상 효과**: 
- Taker 수수료 발생 방지
- Maker 리베이트 확보 (거래소별로 다름, 보통 0.01-0.02%)

### 2. 자체 매칭 방지 (Self-Matching Prevention)

**목적**: 자신의 오픈 주문과 클로즈 주문이 서로 매칭되는 것을 방지

**구현 방법**:
- 새 주문을 넣기 전에 반대편 활성 주문 확인
- 자신의 주문과 가격이 겹치면 가격을 조정하거나 대기
- 주문북에서 자신의 주문 ID 필터링

**예상 효과**:
- 불필요한 거래 감소
- 수수료 절감 (양쪽 모두 수수료 발생 방지)
- 볼륨은 유지하되 실제 거래 비용 감소

### 3. 주문북 깊이 최적화 (Order Book Depth Optimization)

**목적**: Maker 리베이트를 최대화하기 위해 최적의 깊이에 주문 배치

**구현 방법**:
- 주문북 깊이 분석 (Bid/Ask 레벨 확인)
- Maker 리베이트가 높은 깊이에 주문 배치
- 동적 가격 조정: 시장가에서 멀수록 더 높은 리베이트 가능

**예상 효과**:
- Maker 리베이트 최대화
- 주문 체결 확률과 리베이트의 균형 유지

### 4. 주문 취소 최적화 (Order Cancellation Optimization)

**목적**: 불필요한 주문 취소를 줄여 부분 체결로 인한 Taker 수수료 방지

**구현 방법**:
- 주문 취소 전 체결 가능성 재평가
- 가격이 유리한 방향으로 움직이면 취소 대기
- 취소 대기 시간 최적화

**예상 효과**:
- 부분 체결 후 취소로 인한 Taker 수수료 감소
- 주문 효율성 향상

### 5. Maker 리베이트 추적 및 최적화 (Maker Rebate Tracking)

**목적**: Maker 리베이트를 추적하고 최적화

**구현 방법**:
- 거래소별 Maker/Taker 수수료 구조 추적
- 리베이트율 계산 및 로깅
- 리베이트율이 높은 거래소/시장 우선 선택

**예상 효과**:
- 실제 수수료 비용 투명성 확보
- 리베이트 최적화를 통한 순 수수료 감소

### 6. 주문 크기 최적화 (Order Size Optimization)

**목적**: 수수료 구조에 맞춰 주문 크기 조정

**구현 방법**:
- 최소 수수료 요구사항 확인
- 수수료 효율이 높은 주문 크기 계산
- 동적 주문 크기 조정

**예상 효과**:
- 수수료 효율 향상
- 볼륨 대비 수수료 비율 감소

### 7. 배치 주문 관리 (Batch Order Management)

**목적**: API 호출 감소 및 효율성 향상

**구현 방법**:
- 여러 주문을 한 번에 배치 처리
- 주문 그룹화 및 일괄 실행
- API 레이트 리밋 고려

**예상 효과**:
- API 호출 비용 감소
- 실행 효율성 향상

### 8. 스마트 가격 배치 (Smart Price Placement)

**목적**: 체결 확률과 Maker 리베이트의 최적 균형

**구현 방법**:
- 주문북 분석을 통한 최적 가격 계산
- 체결 확률 모델링
- 동적 가격 조정 알고리즘

**예상 효과**:
- 체결률 유지하면서 리베이트 최대화
- 수수료 효율 향상

## 구현 우선순위

### 높은 우선순위 (즉시 효과)
1. **Post-Only 주문 강제** - 가장 간단하고 효과적
2. **자체 매칭 방지** - 구현 난이도 중간, 효과 큼
3. **주문 취소 최적화** - 기존 로직 개선

### 중간 우선순위 (중장기 효과)
4. **Maker 리베이트 추적** - 모니터링 및 최적화 기반
5. **주문북 깊이 최적화** - 복잡하지만 효과적

### 낮은 우선순위 (선택적)
6. **주문 크기 최적화** - 거래소별 상이
7. **배치 주문 관리** - API 지원 필요
8. **스마트 가격 배치** - 고급 기능

## 예상 수수료 절감 효과

현재 전략 (Maker 오픈 + Maker 클로즈):
- Maker 수수료: -0.01% ~ -0.02% (리베이트)
- Taker 수수료: 0.02% ~ 0.05% (실수로 발생 시)

최적화 후:
- Post-Only 강제: Taker 수수료 100% 방지
- 자체 매칭 방지: 불필요한 거래 10-20% 감소
- 주문 취소 최적화: 부분 체결 후 취소로 인한 손실 50% 감소

**예상 총 절감**: 월 거래량의 15-30% 수수료 절감 가능

## 추가 고려사항

1. **거래소별 차이**: 각 거래소의 수수료 구조가 다르므로 거래소별 최적화 필요
2. **볼륨 유지**: 수수료 절감이 볼륨 감소로 이어지지 않도록 주의
3. **복잡도 증가**: 최적화 기능 추가 시 코드 복잡도 증가, 유지보수 고려
4. **테스트 필요**: 각 기능별 충분한 테스트 및 모니터링 필요
