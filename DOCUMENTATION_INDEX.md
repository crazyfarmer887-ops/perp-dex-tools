## 🤝 Contributing to Documentation

### How to Improve Documentation

1. **Found an error?**
   - Open GitHub issue
   - Tag with "documentation"
   - Describe the error and correction

2. **Want to add examples?**
   - Add to [EXAMPLES.md](EXAMPLES.md)
   - Follow existing format
   - Include complete, working code

3. **Need clarification?**
   - Open GitHub issue
   - Ask specific question
   - We'll update docs accordingly

### Documentation Standards

- **Code examples:** Must be complete and runnable
- **Parameters:** Always include type and description
- **Examples:** Include expected output when relevant
- **Links:** Use relative links for internal docs
- **Language:** Clear, concise, beginner-friendly
